# Technology Roadmap Evidence Check

A lightweight static self-assessment derived from this framework.

It checks whether a roadmap has:
- a defined outcome;
- current-state evidence;
- a measurable baseline;
- root-cause analysis;
- capability gaps;
- dependencies;
- explicit prioritisation;
- benefit measures;
- operational ownership;
- control / review.

Result bands:
- Evidence-led roadmap
- Partially evidenced
- Project-list driven

This is not a certification or assurance opinion.

The tool is static HTML/CSS/JavaScript and can be deployed to GitHub Pages or a Hugging Face Static HTML Space with no server-side compute.
