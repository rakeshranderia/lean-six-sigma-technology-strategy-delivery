# Hugging Face / Static Tool Specification

## Working title
**Technology Roadmap Evidence Check**

## Purpose
Assess whether a technology roadmap is evidence-led or primarily a project list.

## Proposed questions
- Is the business outcome explicitly defined?
- Is the current state documented?
- Is there a measurable baseline?
- Have root causes been analysed?
- Are capability gaps stated independently of products?
- Are dependencies visible?
- Are prioritisation criteria explicit?
- Are benefits measurable?
- Is operational ownership defined?
- Is there a control/review mechanism?

## Proposed result bands
- Evidence-led roadmap
- Partially evidenced
- Project-list driven

## Important boundary
The result is a lightweight self-assessment, not a certification.

## Implementation
A static HTML/JavaScript Space is sufficient; no paid compute is required.
