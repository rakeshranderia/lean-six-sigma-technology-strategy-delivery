# Lean Six Sigma Tool Selection Guide

## Decision need
What question are we trying to answer?

## Stage
- Define
- Measure
- Analyse
- Improve
- Control

## Suggested tools

### Define
Voice of Customer · CTQ / Critical-to-Outcome · SIPOC · stakeholder map

### Measure
Baseline metrics · process map · value-stream map · capability / variation analysis

### Analyse
Pareto · 5 Whys · fishbone · FMEA · dependency mapping · Cost of Poor Quality

### Improve
Options matrix · pilot / experiment · value-stream redesign · mistake-proofing

### Control
Control plan · KPI / threshold · ownership / RACI · automated monitoring

## Proportionality check
What is the minimum toolset that provides enough evidence for the decision?
