# Contributing

This repository is intentionally curated.

Contributions are welcome where they:

- improve clarity or practical applicability;
- identify errors or missing edge cases;
- add a useful technology example;
- improve diagrams or templates;
- preserve the distinction between Lean Six Sigma and project/delivery methodologies.

Please open an issue before proposing substantial structural changes.

## Style

- Prefer practical technology language over certification jargon.
- Explain where mappings are approximate rather than implying equivalence.
- Use examples that can be understood across industries.
- Keep diagrams simple and executive-readable.
- Avoid adding process for its own sake.
