# v0.2.0 — Lean, Design & Iterative Delivery

The second public release of **Lean Six Sigma for Technology Strategy & Delivery** expands the foundation into three areas that frequently intersect with modern technology management.

## Added

### Lean Waste in Technology
A practical translation of the eight-waste lens into technology examples covering:

- defects and rework;
- overproduction;
- waiting and queues;
- non-utilised specialist capability;
- unnecessary data movement;
- work-in-progress and unused assets;
- context switching / motion;
- extra-processing and duplicate controls.

The guide deliberately treats the waste categories as prompts rather than forcing manufacturing analogies.

### DMAIC vs DMADV
A decision model for distinguishing:

- **DMAIC** — improving an existing measurable capability;
- **DMADV** — designing a materially new or fundamentally redesigned capability.

Includes technology scenarios and an example where DMAIC analysis leads into DMADV design.

### Agile / Iterative Delivery Overlay
A practical model showing:

**Define → Measure → Analyse → Improve [Backlog → Sprint → Test → Release → Measure → Adapt] → Control**

The positioning is deliberately complementary:

> DMAIC structures the evidence and improvement problem. Agile structures iterative delivery and learning.
