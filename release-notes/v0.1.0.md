# v0.1.0 — Foundation

Initial public foundation release of **Lean Six Sigma for Technology Strategy & Delivery**.

## Included

### Framework
- master Business Need → Strategy → Roadmap → Portfolio → Program → Project → Operations → Benefits lifecycle;
- DMAIC overlay across technology management;
- problem-to-roadmap model;
- management-level crosswalk.

### Worked example
- end-to-end technology-estate rationalisation example;
- baseline, root-cause, capability-gap, roadmap and control model.

### Templates
- technology problem charter;
- current-state baseline;
- capability-gap analysis;
- roadmap prioritisation;
- benefits and control plan.

### Visuals
- master lifecycle;
- DMAIC × management-level matrix;
- problem-to-roadmap flow;
- worked estate-rationalisation flow.

### Publishing plan
- DEV article directions;
- Hashnode article directions;
- Hugging Face interactive-tool concepts.

## Positioning

This release establishes the framework architecture.

It does **not** attempt to reproduce a formal Lean Six Sigma certification curriculum or replace established strategy, portfolio, program, project or Agile methods.
