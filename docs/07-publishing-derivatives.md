## Secondary article

### Strategy, Portfolio, Program and Project Management Through a DMAIC Lens

Use the management-level crosswalk.

The core insight:

- Strategy asks what problem matters.
- Portfolio asks where to invest.
- Program asks whether coordinated change produces the outcome.
- Project asks whether the change is delivered effectively.
- Operations asks whether the improvement lasts.

DMAIC links the evidence chain across all levels.

# HUGGING FACE / INTERACTIVE

The strongest derivative is not another document.

## Tool 1 — Technology Improvement Path

Inputs:

- management level;
- existing vs new capability;
- primary problem type;
- baseline available?;
- root cause understood?;
- solution already selected?;
- outcome measure defined?

Outputs:

- recommended DMAIC or DMADV framing;
- suggested artefacts;
- suggested analysis tools;
- next questions.

---

## Tool 2 — Technology Roadmap Evidence Check

Assess whether a roadmap includes:

- defined business outcomes;
- current-state evidence;
- measurable baseline;
- root-cause analysis;
- capability gaps;
- dependencies;
- prioritisation criteria;
- benefit measures;
- operational ownership.

Possible output labels:

- Evidence-led roadmap
- Partially evidenced
- Project-list driven

Avoid implying formal certification.

# Publication stop rule

Do not publish because a content calendar requires it.

Publish when a module:

1. stands on its own;
2. remains useful outside the original context;
3. suits the platform;
4. adds a different lens rather than duplicating another article.
