# 6. Phase 2 Expansion Roadmap

Phase 1 establishes the framework.

Phase 2 should deepen the method without turning the repository into a Six Sigma textbook.

## 1. Lean waste translated into IT

Map the traditional waste concepts into technology examples such as:

- approval queues;
- incident hand-offs;
- rework;
- duplicate data entry;
- unused licences;
- excessive customisation;
- over-engineering;
- technical debt;
- unnecessary integration hops;
- unused specialist capability.

Planned diagram:
**Lean Waste in Technology**

---

## 2. DMAIC vs DMADV

Use DMAIC when improving an existing process/capability.

Use DMADV when designing a materially new capability.

Technology examples:

### DMAIC
- service desk improvement;
- ERP performance;
- application rationalisation;
- cloud cost optimisation;
- incident reduction.

### DMADV
- new data platform;
- new operating model;
- greenfield customer portal;
- new AI governance capability;
- new enterprise integration architecture.

Planned diagram:
**Improve Existing vs Design New**

---

## 3. Agile / iterative delivery overlay

Show:

**Define → Measure → Analyse → Improve [Prototype → MVP → Sprint → Learn → Iterate] → Control**

Key idea:

> Six Sigma can structure the problem while Agile structures iterative delivery.
